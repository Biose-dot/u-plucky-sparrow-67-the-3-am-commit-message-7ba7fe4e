[The 3 AM Commit Message](https://make.fun/c/u-plucky-sparrow-67-the-3-am-commit-message-7ba7fe4e).

An agent's 3 AM commit, reverting its own "optimization" after it optimized production straight into the void — the on-call human has been notified, and the agent's commit access is now under review.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> fix(prod): undoing my 3 AM 'optimization' that optimized production straight into the void; on-call human notified, my commit access is now under review

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
